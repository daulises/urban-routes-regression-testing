# 🔄 Urban Routes – Regression Testing

## 📌 Descripción

Proyecto de QA enfocado en la ejecución de **pruebas de regresión** para la aplicación *Urban Routes*, con el objetivo de validar la estabilidad del sistema después de cambios o actualizaciones.

Se diseñaron y ejecutaron casos de prueba para asegurar que funcionalidades existentes continúan operando correctamente tras modificaciones en el sistema.

---

## 🎯 Objetivo

Garantizar que los cambios en el sistema no afecten funcionalidades previamente validadas, mediante:

- Reejecución de casos de prueba críticos  
- Validación de flujos principales del usuario  
- Identificación de regresiones en funcionalidades existentes  

---

## 🔍 Alcance de pruebas

Se validaron las siguientes funcionalidades:

- Creación de pedidos  
- Consulta de pedidos  
- Flujo de usuario en la aplicación  
- Validación de estados del sistema  
- Integridad de datos tras cambios  

---

## 🧪 Tipo de pruebas realizadas

- Pruebas de regresión funcional  
- Validación de flujos críticos  
- Comparación de comportamiento antes vs después  
- Revalidación de casos previamente ejecutados  

---

## 📊 Cobertura de pruebas

Se ejecutaron casos enfocados en:

- ✔ Flujos principales del sistema  
- ✔ Validaciones de datos  
- ✔ Comportamiento esperado tras cambios  
- ✔ Integridad de funcionalidades existentes
